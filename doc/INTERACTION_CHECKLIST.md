# YiCAD 交互回归清单

`COMMAND_TOOL_MIGRATION_PLAN.md` 第 6 节第一步第 1 项要求的手工回归清单（主计划 5.6 节
计划过、一直没写）。交互层迁移的每一步、每一批都按本清单在安装后的程序
（`build/<config>/bin/YiCAD.exe`，`cmake --install` 之后）上逐项核对，并在提交说明里
写明核对的配置与结果。

- **期望**写的是迁移前的现有行为，由代码推出，不是理想行为。现有缺陷照原样列出，
  标"既有"，迁移中不顺手修。
- 某一步有意改变的行为记在第 7 节，对应条目的期望同步改写。
- 准备一张图：直线、圆、多段线各若干，至少一个块参照，一段多行文字，一段单行文字；
  另建一个锁定图层，上面放一条线。

## 1. 空闲态选择（没有命令时）

| 编号 | 操作 | 期望 |
|------|------|------|
| S1 | 左键单击一条未选中的线 | 线被选中；状态栏选择计数更新 |
| S2 | 再单击同一条线 | 取消选中（单击是切换） |
| S3 | 单击锁定图层上的线 | 选择状态不变 |
| S4 | 空白处单击，向右下移动，再单击 | 窗选：只选中完全落在框内的实体；移动时显示选择框 |
| S5 | 空白处单击，向左移动，再单击 | 交叉选：与框相交的实体也被选中 |
| S6 | 框选第二次单击时按住 Shift | 框内实体被取消选中 |
| S7 | 框选中途右键 | 框选取消，回到初始状态 |
| S8 | 选中一条线，在它的端点附近（8 像素内）按住左键拖动超过 10 像素后松开，移动鼠标，再单击 | 夹点拖拽：端点跟随鼠标（有捕捉），单击后落位，可撤销 |
| S9 | 选中若干实体，在其中一个上按住拖动超过阈值后松开，移动，再单击 | 拖动实体：选中的实体整体预览跟随，单击后移动，可撤销 |
| S10 | S8/S9 移动过程中按住 Shift | 以 15° 为步进角度吸附，并显示一条引导线 |
| S11 | 双击一条线（没有其它选择） | 弹出属性对话框 |
| S12 | 双击多行文字 | 进入多行文字编辑（见 6.2 节） |
| S13 | 选中两个以上实体后双击 | 无反应 |
| S14 | 空闲态移动鼠标 | 光标为箭头；坐标栏随鼠标更新 |

## 2. 键盘、导航与光标

| 编号 | 操作 | 期望 |
|------|------|------|
| K1 | 空闲态有选择时按 Esc | 选择清空（状态栏计数不刷新，既有）；进行中的框选/拖动取消 |
| K2 | 空闲态按空格 | 结束全部命令，清空选择，状态栏计数刷新，命令行清空 |
| K3 | 画直线途中按 Esc | 直线命令按自身逻辑处理 Esc；未接受时结束全部命令并清空选择 |
| K4 | 空闲态按回车（主键盘、小键盘） | 无反应 |
| K5 | 空闲态按 Delete | 删除选择集 |
| N1 | 空闲态按住中键拖动 | 平移；拖动中光标为抓手，松开后恢复箭头 |
| N2 | 画直线途中按住中键拖动 | 平移；直线命令保持活动，预览不丢 |
| N3 | 空闲态按住 Ctrl+左键拖动 | 平移，不产生框选 |
| N4 | 画直线途中按 Ctrl+左键 | 交给直线命令（不平移） |
| N5 | 中键双击 | 适屏显示 |
| N6 | 滚轮 | 以光标为中心缩放；缩放后框选/拖动中的状态保持 |
| N7 | 鼠标移出画布再移回 | 空闲态：预览与捕捉标记清除后恢复；命令中：命令自己的预览恢复 |
| N8 | 拖动实体（S9）时经过端点 | 画布显示捕捉标记，并弹出捕捉类型提示（如 Endpoint） |
| Z1 | Ribbon"平移"，按住左键拖动后松开 | 视图随拖动平移（超过 7 像素才动）；光标等待时为张开的手，拖动中为握紧的手 |
| Z2 | 平移模式中右键（或命令行输入 escape） | 退出平移模式，回到进入前的状态；光标恢复 |
| Z3 | 画直线途中（已指定起点）进入平移模式，拖动后右键 | 平移期间直线预览与捕捉标记消失；退出后回到画直线，预览恢复，提示为画直线的 |
| Z4 | 平移模式中按 Esc；再进入一次，按空格 | 结束全部命令并清空选择 |
| Z5 | 平移模式中从 Ribbon 启动画直线 | 平移模式结束，进入画直线；画完后不回到平移模式（第三步起，见第 7 节） |
| Z6 | 平移模式中按住中键拖动；中键双击 | 平移（导航层）；适屏显示。仍在平移模式 |
| Z7 | 平移模式中在命令行输入坐标 `10,10`；再输入 `line` | 坐标被丢弃；`line` 启动画直线（平移模式随之结束） |
| Z8 | Ribbon 放大、缩小（空闲态、画直线途中、多行文字编辑中各一次） | 以视图中心缩放；当前命令不结束，多行文字编辑不弹保存提示 |
| Z9 | 画直线途中、多行文字编辑中滚动滚轮 | 以光标为中心缩放；命令继续，选项条不闪烁（第三步起，见第 7 节） |
| U1 | 画直线途中从快速访问栏撤销、重做 | 文档撤销、重做一步；直线命令继续，预览不丢 |
| U2 | 画直线（连续画两段）后，在直线选项条上点"撤销"、再点"重做" | 最后一段被撤销、再恢复；起点随之回退、前进 |
| U3 | 选中一条样条和一条直线后执行"选中信息"（info.selected） | 命令行输出两者的类型、ID、图层，样条另有起终点、节点与控制点 |

## 3. 先选后建命令的选择阶段

14 个命令：移动 `modify.move`、复制 `modify.copy`、旋转 `modify.rotate`、缩放
`modify.scale`、镜像 `modify.mirror`、分解 `modify.explode`、反向 `modify.reverse`、
删除 `modify.delete`、复制到剪贴板 `edit.copy`、剪切 `edit.cut`、复制到图层
`modify.copy_to_layer`、创建块 `blocks.create`、编辑块 `blocks.edit`、总长度
`info.total_length`。

| 编号 | 操作 | 期望 |
|------|------|------|
| P1 | 没有选择时逐个启动 14 个命令 | 进入"选择对象"阶段，光标为选择光标。按键提示 14 个命令相同："Click and drag for the selection window" / "Cancel"；框选第二点时 "Choose second edge" / "Back"（第二步核对代码后更正：原 `ActionSelect` 按命令给出的 "Select to …" 提示被叠在它上面的 `ActionSelectMultiple` 覆盖，从未显示过） |
| P2 | 选择阶段点选、框选、交叉选 | 与 S1–S6 相同 |
| P3 | 选择阶段有选择后按回车（主键盘、小键盘各一次） | 进入真正的命令 |
| P4 | 选择阶段没有选择时按回车 | 无反应，仍在选择阶段 |
| P5 | 选择阶段右键 | 结束整个命令，回到空闲态 |
| P6 | 选择阶段按 Esc；再启动一次，按空格 | Esc：结束全部命令并清空选择。空格：无反应，仍在选择阶段（第二步核对代码后更正：原 `ActionSelectMultiple` 不忽略空格，主窗口因此不结束命令） |
| P7 | 已有选择时启动除删除外的 13 个命令 | 跳过选择阶段，直接进入真正的命令 |
| P8 | 已有选择时启动删除 | 仍先进入选择阶段（既有，主计划 7.7 节） |
| P9 | 选择阶段按住 Ctrl+左键拖动 | 框选，不平移（空闲态的 N3 在选择阶段不适用） |
| P10 | 选择阶段双击一个实体 | 无反应（不弹属性对话框、不进入文字编辑） |
| P11 | 选择阶段选中一条线，在它的端点上按住拖动 | 框选，不拖夹点也不拖实体 |
| P12 | 选择阶段选中实体后按 Delete | 选中的实体被删除，仍在选择阶段 |
| P13 | 画直线途中从 Ribbon 启动删除，右键结束删除 | 直线命令结束，不再恢复（第二步起，见第 7 节） |

## 4. 块编辑

| 编号 | 操作 | 期望 |
|------|------|------|
| B1 | 选中一个块参照后启动编辑块 | 进入块编辑：视图适屏到块内容；提示 "Edit block entities" / "Finish / Cancel"；选项条出现 |
| B2 | 块编辑中点选、框选、拖动实体、拖夹点 | 与 S1–S10 相同，作用于块内实体 |
| B3 | 块编辑中点选后看按键提示 | 仍为 "Edit block entities" / "Finish / Cancel" |
| B4 | 块编辑中按 Esc | 清空块内选择，仍在块编辑 |
| B5 | 块编辑中双击实体 | 无反应（既有） |
| B6 | 块编辑中启动画直线，画完后右键结束 | 直线画进块内；结束后回到块编辑 |
| B7 | 块编辑中右键 | 弹出"Finish editing and save changes?"（是/否/取消）：是保存并退出，否放弃修改并退出，取消继续编辑 |
| B8 | 块编辑中中键拖动 | 平移 |
| B9 | 块编辑中撤销到进入之前，再重做 | 撤销后退出块编辑；重做后重新进入块编辑 |
| B10 | 块编辑中按空格；再试 Ribbon 上的"结束全部命令" | 弹出"Finish editing and save changes?"（是/否/取消）：是保存并退出，否放弃修改并退出，取消则继续编辑、选择集不清空（第二步起，见第 7 节） |
| B11 | 块编辑中执行文件保存（或新建、打开、插入块） | 先弹出 B10 的对话框；取消则不执行该命令，继续编辑 |
| B12 | 块编辑中选中实体后从 Ribbon 创建块，指定参考点并命名 | 块在块内创建；结束后仍在块编辑，选项条仍在 |
| B13 | 块编辑中关闭该图纸标签页 | 不提问块编辑的保存，按图纸本身的保存提示处理 |

## 6A. 绘图与修改命令（第三步起）

业务工具化第三步把绘图、修改命令从旧 Action 迁成命令 + 放置工具，逐批补充条目。
共同的期望：启动后提示为第一步；右键退回上一步，在第一步时结束命令；Esc/空格结束
全部命令；中键平移、滚轮缩放后命令照常继续；有选项条的命令启动时出现选项条，结束后
消失；在命令中从 Ribbon 启动另一个旧版命令，结束后回到本命令，选项条恢复。
