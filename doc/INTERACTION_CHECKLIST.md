# YiCAD 交互回归清单

`COMMAND_TOOL_MIGRATION_PLAN.md` 第 6 节第一步第 1 项要求的手工回归清单（主计划 5.6 节
计划过、一直没写）。交互层迁移的每一步、每一批都按本清单在安装后的程序
（`build/<config>/bin/YiCAD.exe`，`cmake --install` 之后）上逐项核对，并在提交说明里
写明核对的配置与结果。

- **期望**写的是迁移前的现有行为，由代码推出，不是理想行为。现有缺陷照原样列出，
  标"既有"，迁移中不顺手修。
- 某一步有意改变的行为记在第 7 节，对应条目的期望同步改写。
- 准备一张图：直线、圆、多段线各若干，至少一个块参照，一段多行文字，一段单行文字；
  另建一个锁定图层，上面放一条线。

## 1. 空闲态选择（没有命令时）

| 编号 | 操作 | 期望 |
|------|------|------|
| S1 | 左键单击一条未选中的线 | 线被选中；状态栏选择计数更新 |
| S2 | 再单击同一条线的线身（不在端点 8 像素内） | 取消选中（单击是切换）；单击端点见 S8 |
| S3 | 单击锁定图层上的线 | 选择状态不变 |
| S4 | 空白处单击，向右下移动，再单击 | 窗选：只选中完全落在框内的实体；移动时显示选择框 |
| S5 | 空白处单击，向左移动，再单击 | 交叉选：与框相交的实体也被选中 |
| S6 | 框选第二次单击时按住 Shift | 框内实体被取消选中 |
| S7 | 框选中途右键 | 框选取消，回到初始状态 |
| S8 | 选中一条线，单击它的端点（8 像素内），移动鼠标，再单击 | 夹点激活：线保持选中，端点跟随鼠标（有捕捉），单击后落位，可撤销 |
| S9 | 选中若干实体，在其中一个的线身上按住拖动超过 10 像素 | 开始框选，不移动实体（空闲态不能拖动整个实体，移动用移动命令） |
| S10 | S8 移动过程中按住 Shift | 以 15° 为步进角度吸附，并显示一条引导线 |
| S11 | 双击一条线（没有其它选择） | 弹出属性对话框 |
| S12 | 双击多行文字 | 进入多行文字编辑（见 6.2 节） |
| S13 | 选中两个以上实体后双击 | 无反应 |
| S14 | 空闲态移动鼠标 | 光标为箭头；坐标栏随鼠标更新 |
| S15 | S8 夹点激活后右键 | 夹点取消，跟随鼠标的预览消失，选择保留 |
| S16 | S8 夹点激活后从 Ribbon 启动画直线，画完或取消后单击画布 | 启动时夹点取消；回到空闲态后单击是点选，不再移动端点 |
| S17 | 选中一条线，在它的端点上按住拖动超过 10 像素后松开，移动，再单击 | 与 S8 相同：拖过阈值时夹点激活，松开后继续跟随，单击落位 |
| S18 | 选中一条线，双击它的端点 | 夹点激活，不打开属性对话框（双击线身见 S11） |

## 2. 键盘、导航与光标

| 编号 | 操作 | 期望 |
|------|------|------|
| K1 | 空闲态有选择时按 Esc | 选择清空（状态栏计数不刷新，既有）；进行中的框选/拖动取消 |
| K2 | 空闲态按空格 | 结束全部命令，清空选择，状态栏计数刷新，命令行清空 |
| K3 | 画直线途中按 Esc | 直线命令按自身逻辑处理 Esc；未接受时结束全部命令并清空选择 |
| K4 | 空闲态按回车（主键盘、小键盘） | 无反应 |
| K5 | 空闲态按 Delete | 删除选择集 |
| N1 | 空闲态按住中键拖动 | 平移；拖动中光标为抓手，松开后恢复箭头 |
| N2 | 画直线途中按住中键拖动 | 平移；直线命令保持活动，预览不丢 |
| N3 | 空闲态按住 Ctrl+左键拖动 | 平移，不产生框选 |
| N4 | 画直线途中按 Ctrl+左键 | 交给直线命令（不平移） |
| N5 | 中键双击 | 适屏显示 |
| N6 | 滚轮 | 以光标为中心缩放；缩放后框选/拖动中的状态保持 |
| N7 | 鼠标移出画布再移回 | 空闲态：预览与捕捉标记清除后恢复；命令中：命令自己的预览恢复 |
| N8 | 夹点激活（S8）后经过其他实体的端点 | 画布显示捕捉标记，并弹出捕捉类型提示（如 Endpoint） |
| Z8 | Ribbon 放大、缩小（空闲态、画直线途中、多行文字编辑中各一次） | 以视图中心缩放；当前命令不结束，多行文字编辑不弹保存提示 |
| Z9 | 画直线途中、多行文字编辑中滚动滚轮 | 以光标为中心缩放；命令继续，选项条不闪烁（第三步起，见第 7 节） |
| U1 | 画直线途中从快速访问栏撤销、重做 | 文档撤销、重做一步；直线命令继续，预览不丢 |
| U2 | 画直线（连续画两段）后，在直线选项条上点"撤销"、再点"重做" | 最后一段被撤销、再恢复；起点随之回退、前进 |
| U3 | 选中一条样条和一条直线后执行"选中信息"（info.selected） | 命令行输出两者的类型、ID、图层，样条另有起终点、节点与控制点 |

## 3. 先选后建命令的选择阶段

14 个命令：移动 `ext.modify.move`、复制 `ext.modify.copy`、旋转 `ext.modify.rotate`、缩放
`ext.modify.scale`、镜像 `ext.modify.mirror`、分解 `ext.modify.explode`、反向 `ext.modify.reverse`、
删除 `ext.modify.delete`、复制到剪贴板 `ext.edit.copy`、剪切 `ext.edit.cut`、复制到图层
`ext.modify.copy_to_layer`、创建块 `ext.block.create`、编辑块 `ext.block.edit`、总长度
`ext.measure.total_length`（第四步起的 ID，原先是 `modify.move` 等）。

| 编号 | 操作 | 期望 |
|------|------|------|
| P1 | 没有选择时逐个启动 14 个命令 | 进入"选择对象"阶段，光标为选择光标。按键提示 14 个命令相同："Click and drag for the selection window" / "Cancel"；框选第二点时 "Choose second edge" / "Back"（第二步核对代码后更正：原 `ActionSelect` 按命令给出的 "Select to …" 提示被叠在它上面的 `ActionSelectMultiple` 覆盖，从未显示过） |
| P2 | 选择阶段点选、框选、交叉选 | 与 S1–S6 相同 |
| P3 | 选择阶段有选择后按回车（主键盘、小键盘各一次） | 进入真正的命令 |
| P4 | 选择阶段没有选择时按回车 | 无反应，仍在选择阶段 |
| P5 | 选择阶段右键 | 结束整个命令，回到空闲态 |
| P6 | 选择阶段按 Esc；再启动一次，按空格 | Esc：结束全部命令并清空选择。空格：无反应，仍在选择阶段（第二步核对代码后更正：原 `ActionSelectMultiple` 不忽略空格，主窗口因此不结束命令） |
| P7 | 已有选择时启动除删除外的 13 个命令 | 跳过选择阶段，直接进入真正的命令 |
| P8 | 已有选择时启动删除 | 仍先进入选择阶段（既有，主计划 7.7 节） |
| P9 | 选择阶段按住 Ctrl+左键拖动 | 框选，不平移（空闲态的 N3 在选择阶段不适用） |
| P10 | 选择阶段双击一个实体 | 无反应（不弹属性对话框、不进入文字编辑） |
| P11 | 选择阶段选中一条线，在它的端点上按住拖动 | 框选，不拖夹点也不拖实体 |
| P12 | 选择阶段选中实体后按 Delete | 选中的实体被删除，仍在选择阶段 |
| P13 | 画直线途中从 Ribbon 启动删除，右键结束删除 | 直线命令结束，不再恢复（第二步起，见第 7 节） |

## 4. 块编辑

| 编号 | 操作 | 期望 |
|------|------|------|
| B1 | 选中一个块参照后启动编辑块 | 进入块编辑：视图适屏到块内容；提示 "Edit block entities" / "Finish / Cancel"；选项条出现 |
| B2 | 块编辑中点选、框选、夹点编辑 | 与 S1–S10、S17 相同，作用于块内实体 |
| B3 | 块编辑中点选后看按键提示 | 仍为 "Edit block entities" / "Finish / Cancel" |
| B4 | 块编辑中按 Esc | 清空块内选择，仍在块编辑 |
| B5 | 块编辑中双击实体 | 无反应（既有） |
| B6 | 块编辑中启动画直线，画完后右键结束 | 直线画进块内；结束后回到块编辑 |
| B7 | 块编辑中右键 | 弹出"Finish editing and save changes?"（是/否/取消）：是保存并退出，否放弃修改并退出，取消继续编辑 |
| B8 | 块编辑中中键拖动 | 平移 |
| B9 | 块编辑中撤销到进入之前，再重做 | 撤销后退出块编辑；重做后重新进入块编辑 |
| B10 | 块编辑中按空格；再试 Ribbon 上的"结束全部命令" | 弹出"Finish editing and save changes?"（是/否/取消）：是保存并退出，否放弃修改并退出，取消则继续编辑、选择集不清空（第二步起，见第 7 节） |
| B11 | 块编辑中执行文件保存（或新建、打开、插入块） | 先弹出 B10 的对话框；取消则不执行该命令，继续编辑 |
| B12 | 块编辑中选中实体后从 Ribbon 创建块，指定参考点并命名 | 块在块内创建；结束后仍在块编辑，选项条仍在 |
| B13 | 块编辑中关闭该图纸标签页 | 不提问块编辑的保存，按图纸本身的保存提示处理 |

## 6. 多行文字

### 6.1 属性面板（第三步⑦起为 `ext.text.modify_mtext`，原 `ActionModifyMText`）

| 编号 | 操作 | 期望 |
|------|------|------|
| M1 | 空闲态单击选中一段多行文字 | 左上出现多行文字属性面板（字高、样式、角度、行距） |
| M2 | 在面板里改字高 | 立即生效，每次改动可单独撤销 |
| M3 | 面板出现后在画布上单击 | 文字取消选中，面板关闭 |
| M4 | 面板出现后双击同一段文字 | 面板关闭，进入 6.2 节的文字编辑 |

### 6.2 文字编辑（第三步⑦起为 `ext.text.mtext`/`ext.text.edit_mtext`，原 `ActionDrawMText` 编辑态）

| 编号 | 操作 | 期望 |
|------|------|------|
| T1 | 双击多行文字，修改内容后点 Ribbon 上的直线 | 弹出 "Save the changes?"（是/否）：是则提交修改，否则放弃；随后进入画直线 |
| T2 | 同上，改为执行"结束全部命令" | 弹出同样的提示，按选择提交或放弃，回到空闲态 |
| T3 | 同上，改为关闭该图纸标签页 | 关闭前弹出同样的提示 |
| T4 | 不做修改直接执行 T1–T3 | 同样弹出提示（编辑态一律提示，不看是否修改） |
| T5 | 双击多行文字编辑中点快速访问栏的"撤销"（编辑框里的 Ctrl+Z 撤销的是编辑框里的输入） | 先弹出同样的提示，按选择提交或放弃，再撤销 |
| T6 | 修改实体属性命令中点一段多行文字，在面板里改字高，再在画布上单击 | 面板出现并生效；单击后面板关闭、回到空闲态（第三步⑦起，原先回到修改实体属性） |
| T7 | 单行文字：命令行输入 text，再输入一段文字；右键；随后画直线时命令行输入坐标 | 文字替换为输入的内容；坐标照常生效（第三步⑦起修复） |

## 6A. 绘图与修改命令（第三步起）

业务工具化第三步把绘图、修改命令从旧 Action 迁成命令 + 放置工具，逐批补充条目。
共同的期望：启动后提示为第一步；右键退回上一步，在第一步时结束命令；Esc/空格结束
全部命令；中键平移、滚轮缩放后命令照常继续；有选项条的命令启动时出现选项条，结束后
消失；在命令中从 Ribbon 启动另一个旧版命令，结束后回到本命令，选项条恢复。

| 编号 | 操作 | 期望 |
|------|------|------|
| D1 | 画直线：连续指定三点，再在选项条上点"闭合" | 画出三角形；按住 Shift 移动时以 15° 吸附 |
| D2 | 画直线：画两段后在选项条上点"撤销"、"重做"；命令行输入 undo | 与 U2 相同；undo 撤销一段 |
| D3 | 画直线途中在命令行输入任意文字（如 circle） | 被当作 redo：提示"Cannot redo: End of history reached"，不启动新命令（既有） |
| D4 | 画直线：指定起点后右键 | 开始新的线段组，回到"Specify first point"；再右键结束命令 |
| D5 | 画多段线：直线段、切选项条模式为"相切""相切定半径""定角度"各画一段；设起止线宽 | 圆弧段按模式预览与落下；有线宽时预览为填充四边形 |
| D6 | 画多段线：画三段后命令行输入 close；再画两段输入 undo | 闭合；撤销最后一点 |
| D7 | 画矩形：两个对角点 | 画出闭合多段线；继续可画下一个 |
| D8 | 正交限制（Restrict Orthogonal）下画矩形、正多边形 | 画完一个后命令结束（既有） |
| D9 | 正多边形（中心+角点、中心+切点）：选项条改边数为 6 | 预览与结果都是六边形；两种命令都有选项条 |
| D10 | 正多边形：命令行输入 number，再输入 8 | 提示"Enter number:"，随后边数为 8，选项条同步 |
| D11 | 角平分线：选两条相交直线，选项条改长度与数量 | 高亮、预览、落下若干条等分线；提交后高亮取消 |
| D12 | 过点切线、两圆公切线、正交切线：各画一条 | 被选的圆高亮，预览最近的切线；单击落下；Esc 结束后高亮取消 |
| D13 | 两圆公切线：选中第一个圆后立即按 Esc | 命令结束，不崩溃（第三步起修复） |
| D14 | 徒手线：按住左键拖动后松开，重复一次 | 每次松开落下一条多段线；随后画直线，预览正常 |
| D15 | 射线、构造线：指定基点后右键 | 回到"指定第一点"（不结束）；提示为中文（第三步起） |
| D16 | 画点：连续单击几处；右键 | 每次单击画一个点；右键结束 |
| D17 | 圆心圆弧：选项条切到顺时针，画一段；再画一段 | 第一段按顺时针；第二段回到逆时针（既有：每段复位） |
| D18 | 三点圆弧：命令行输入任意文字（如 x） | 切换为圆心圆弧（既有），文字随后当作新命令解析 |
| D19 | 相切圆弧：选直线一端，选项条锁定半径 | 预览与结果按锁定半径；选项条的半径/角度随鼠标刷新 |
| D20 | 圆（圆心、两点、三点）、两切圆、三切圆：各画一个；两切圆在选项条改半径 | 预览与结果正确；被选实体高亮，结束后取消 |
| D21 | 椭圆、椭圆弧：各画一个；内切椭圆选四条线 | 椭圆弧用鼠标指定终止角后结束命令（既有） |

| D24 | 插入图片：取消文件对话框；再选一张图片并放下 | 取消时回到空闲态；放下后命令结束，选项条的角度与缩放生效 |
| D25 | 修剪：单击一两条边界后按小键盘回车；悬停到要剪的实体上再单击；再按小键盘回车 | 悬停时预览剪掉的部分（原实体暂时隐藏）；单击剪掉，可继续；第二次回车结束。主键盘回车不切换（既有） |
| D26 | 修剪：悬停出预览时右键；再悬停出预览时按 Esc | 右键回到"选择边界"，Esc 结束；两种情况原实体都重新显示（第三步起修复） |
